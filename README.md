# MathMaster Update Host

This public repository stores only the signed Android release asset and update metadata used by MathMaster's in-app updater.

- `updates/update.json` is published by the private `mathsbj` release workflow.
- The `latest` GitHub Release hosts `MathMaster-release.apk`.

Application source code, signing keys, credentials, and private data must remain in the private `sudhanshu1920/mathsbj` repository.
